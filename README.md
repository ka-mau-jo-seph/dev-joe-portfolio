# Dev Joe — Portfolio

Personal portfolio of **Joseph Kamau Ngigi**, a web developer and graphic designer based in Limuru, Kenya.

**Live site: [joe-acts.netlify.app](https://joe-acts.netlify.app/)**

![Portfolio home page](folio-desktop.jpg)

## Pages

| Page | What's on it |
| --- | --- |
| **Home** | Portrait hero, typing role line, skills ticker, a code sample from the Wamaina Gas system |
| **About** | My story, experience, journey timeline, education, ERP training certificate and a downloadable resume |
| **Skills** | Front end, back end, database, and design and video tools, plus where I've used each one |
| **Projects** | Wamaina Gas Management System (with an interactive stock demo), the Wamaina Gas Suppliers website, and this portfolio |
| **Design** | Gallery of logos, business cards, flyers and social media posters, plus promo videos and logo animations |
| **Contact** | Email, phone, resume download and a contact form |

## Features

- Multi-page site with a shared navbar and a mobile menu
- Light and dark themes that follow the visitor's settings and remember their choice
- Interactive cylinder stock demo, written in plain JavaScript
- Design gallery with category filters and a full-screen viewer (arrow keys and swipe)
- Contact form with input checks that prepares an email in the visitor's mail app
- Downloadable one-page PDF resume
- Responsive layout for phones, tablets and desktops

## Built with

HTML, CSS and vanilla JavaScript — no frameworks or build step. Fonts: Bricolage Grotesque, IBM Plex Sans and IBM Plex Mono from Google Fonts.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Deployed on Netlify from this repository: every push to `main` updates [joe-acts.netlify.app](https://joe-acts.netlify.app/). The site is static, so no build command is needed and the publish directory is the project root.
